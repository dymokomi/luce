# Common examples

Programs written in the subset both Luce Base and full Luce accept: scalars,
structs, enums, functions, control flow, and `defer`. A program here must
check, run, and build unchanged as a `.luc` and as a `.lucb` module. The
folder is empty until the first such pair lands; Base-only programs live in
`../base` and the rest of the language in `../full`.
