# A Tour of Luce

An introduction in ten chapters. Each one is built around programs you can copy into a
file and run, and each ends with a pointer to the next.

1. [Hello, Luce](01-hello.md): installing, a first program, a first project
2. [Values](02-values.md): bindings, numbers, text and conversions
3. [Collections and loops](03-collections-and-loops.md): lists, maps, sets, tuples, `for` and `match`
4. [Functions](04-functions.md): parameters, defaults, named arguments, lambdas and closures
5. [Structs and enums](05-structs-and-enums.md): your own value types and their methods
6. [Classes](06-classes.md): shared objects, their lifetime, and closing resources
7. [Absence and failure](07-absence-and-failure.md): optionals, errors and traps
8. [Interfaces and generics](08-interfaces-and-generics.md): code that works on many types
9. [Projects and packages](09-projects-and-packages.md): modules, dependencies and tests
10. [Workers, and where next](10-workers-and-where-next.md): work in parallel, and what lies beyond the Tour

The Tour assumes you have programmed before, most likely in Python, and compares Luce with
it where that helps.
